
SITE OVERVIEW
Nona’s Cross-Stitches is a React single-page e-commerce site built with Vite, React Router, and Tailwind CSS. Theme colors and typography are defined in src/styles/Theme.css. Main code lives in src/pages, src/components, and src/context.

HOW THE SITE WORKS
The router is configured in src/AppRoute.jsx. The home page links to a product catalog, product details, and checkout. Catalog products and category filters are in src/pages/catalog/catalogData.js. Cart state is shared through src/context/CartContext.jsx. Delivery and payment options are shared by checkout, order confirmation, and the Delivery & Payment page. The global footer is in src/components/layout/Footer.jsx; Checkout keeps a minimal layout without the footer.
